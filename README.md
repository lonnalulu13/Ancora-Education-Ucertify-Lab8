# Converting a Basic Disk to a Dynamic Disk

A basic disk in Windows uses traditional partitions (primary and extended) to organize data, while a dynamic disk offers advanced features like spanning multiple disks, mirroring, striping, and RAID volumes for enhanced data management and fault tolerance. Dynamic disks are suitable for more complex storage setups, while basic disks are simpler and better for general use.

## Instructions
## Part A: Converting a Basic Disk to a Dynamic Disk
Open the Computer Management window and navigate to Storage > Disk Management. Convert Disk 1 from basic to dynamic.

### STEP 1
Right-click the Start menu and select Computer Management.

### STEP 2
In the left pane, under Storage, click Disk Management.

### STEP 3
Right-click Disk 1 and select Convert to Dynamic Disk.

**NOTE**

Note When you change a basic disk to a dynamic disk, you can create volumes that span multiple disks. Dynamic volumes can be used in most but not all situations. Basic disks support only primary partitions, extended partitions, and logical drives.Converting a basic disk to a dynamic disk is a one-way process. Once you convert, you cannot easily revert to a basic disk without data loss.

### STEP 4
At the Convert to Dynamic Disk prompt, click OK.

### STEP 5
Click Convert to convert the disk.

### STEP 6
At the Disk Management prompt, click Yes.
